# Synopsis

The Open Group says ArchiMate 3 tools in its certification program have been required to support MEFF since June 2018. Its certification page describes a formal submission and audit process, and identifies a Test Model directory whose access requires member login.[^opengroup-archimate-certification]

# Use in archimate-js

Use the public XSDs and examples to improve the declared and tested compatibility profile. Do not describe the library as certified, conformant, or equivalent to the restricted certification test suite without completing the applicable program and obtaining evidence.

# Constraints

Certification status and use of The Open Group's marks are controlled by the program and its agreements. A public schema check or an interoperability example is useful engineering evidence but is not a substitute for certification.[^opengroup-meff-faq]
