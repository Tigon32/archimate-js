# README screenshot assets

`viewer.svg` and `viewer-high-contrast-dark.svg` are deterministic text SVGs
generated by `npm run docs:screenshots` from
`test/fixtures/synthetic/read-only-showcase.xml`.

The source fixture is classified as **SYNTHETIC** in
`test/fixtures/manifest.json`. The SVGs are documentation renderings of that
fixture only; they do not contain customer, private, or production architecture
data.
