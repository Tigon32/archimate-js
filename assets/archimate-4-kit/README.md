# ArchiMate 4 styling extract

These files were copied without modification from the user-provided
`archimate-4-kit.zip`:

- `tokens/tokens.json` — notation and layout tokens
- `css/archimate.css` — CSS variables and notation styles generated from those
  tokens
- `svg/archimate-symbols.svg` — reusable notation symbols

Use these as the supplied notation source when integrating the renderer. Keep
application-shell controls in a separate style layer. Do not add the private
`spec/` or `catalog/` material from the source kit to this public repository.
